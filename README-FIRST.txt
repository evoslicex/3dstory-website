3DStory website starter
========================

This is a static website starter for 3dstory.in.

Before launch, replace:
1. Placeholder product-image boxes with your actual product photos.
2. The WhatsApp button/action with your real WhatsApp number.
3. Instagram and email placeholders.
4. Any pricing you want to display.
5. Privacy/Terms/Refund/Shipping text after reviewing it for your actual business.
6. Canonical URLs if you add/remove pages.

Deployment path:
GoDaddy domain -> Cloudflare DNS -> Cloudflare Pages -> GitHub repository.

The site is static HTML/CSS and does not require WordPress or paid hosting.
